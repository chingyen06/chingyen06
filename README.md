**技術:** `Python`  

### [**影像辨識**](https://github.com/chingyen06/Multimedia-Applications/):
包含多項專案內容:  
1. 以邊緣偵測的方式，對同個圖片新增不同濾鏡效果  
2. 以MediaPipe Face Mesh 擷取臉部關鍵點並計算嘴部幾何特徵，若微笑則以邊緣偵測的方式套用濾淨效果
3. 以 YOLO26m 辨識監視器影像中的車輛，自建資料集 200 張並標示 Bounding Box 進行訓練
4. 以 ResNet-18 辨識車道線 (直線 / 曲線皆可)，使 Jetbot 能自行根據車道線行走，自建資料集 200 張進行訓練  
5. 以 Canny + Hough Transform 與 YOLOv4-tiny，分別辨識車道線 (直線) 以及道路指示牌，使 Jetbot 能自行根據車道線行走，並針對辨識出的指示牌內容做出不同行為  
6. 以 ResNet-18 與 YOLOv4-tiny，分別辨識車道線 (直線 / 曲線皆可) 以及道路指示牌，使 Jetbot 能自行根據車道線行走，並針對辨識出的指示牌內容做出不同行為

**技術:** `Python`, `OpenCV`, `MediaPipe`, `PyTorch`, `ResNet-18`, `YOLO26m`, `YOLOv4-tiny`, `TensorRT`, `ONNX`, `Jetbot`, `Jetson Nano`
